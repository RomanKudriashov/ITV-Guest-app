# Отчёт R2 — Кросс-ссылки, overlay, разъезд заказа

Ветка `r2/cross-refs-overlay` (от `r1/service-model`). Базис до прогона: ~456
backend / 36 E2E. Читать с `guest-hub-design-map.md` (Часть 0) и `-rebuild-plan.md`.

## Что сделано (по коммитам)

- **C1 — модель включений.** `ServiceInclusion` (+ join'ы `selected_categories`/
  `hidden_items`): включение контента по ссылке; overlay scope/markup/schedule/
  executor. Запрет самовключения (CheckConstraint) и циклов (обход графа при
  записи, `409 inclusion_cycle`). CMS API `/cms/services/{id}/inclusions`. RLS.
- **C2 — резолвер эффективного каталога.** `borrowed_blocks`, `resolve_item_executor`,
  `apply_overlay_availability`. `build_menu` доклеивает заимствованные блоки
  (наценка/скрытие/доступность-пересечение); не-заимствующий сервис — байт-в-байт.
- **C3 — разъезд заказа (суб-заказы).** `Order.parent`; `create_order` группирует
  строки по исполнителю (1 → плоский как раньше, N → parent+children). Деньги —
  один снимок на parent (коммерция агрегатора); статус — свод из children; отмена
  каскадит; гостю один заказ; трекер без parent.
- **C4 — аналитика паритета.** Единица — parent (деньги + агрегат позиций с
  исполнителями children); children пропускаются. Пересчёт == живой поток.
- **C5 — посев (флаг `--with-rich-catalog`).** Рум-сервис включает «Панораму»
  целиком (+15%, круглосуточно, «Сырники» скрыты) и коктейли бара; демо-заказ
  разъезжается на кухню + бар.
- **C6 — контракты + i18n + отчёт.** `docs/inclusions-api-contract.md`; 4-язычные
  метки включений (vocabularies).

## Как устроено

- **Включение — ссылка, не копия.** Заимствованная позиция — та же `Item`-строка
  источника; overlay (наценка/скрытие/расписание) применяется на резолве, не
  хранится копией. Правка позиции/стоп-листа в источнике видна заёмщику сразу —
  единый источник правды.
- **Эффективный исполнитель** позиции (`resolve_item_executor`): своя → точка
  сервиса; заимствованная → точка по overlay (`source`/`own`). Один выбор решает
  и маршрут заказа, и чьё расписание в силе.
- **Доступность = пересечение** доступности источника и расписания блока.
- **Fan-out = суб-заказы.** parent — гостевой агрегат (снимок сумм, канал,
  статус-свод); children — исполнение (по одному на исполнителя, каждый на своей
  доске через существующий `build_board`). Не-заёмный заказ (один исполнитель) —
  плоский, как раньше. Смена статуса child пересчитывает свод parent и дотолкивает
  канал гостя.
- **Коммерция корзины — включающего сервиса** (сбор/доставка/минимум); цена
  заимствованной строки в снимке — с наценкой. `quote_cart` сходится со снимком.

## Что удалено
Ничего не удалялось: R2 — надстройка логики над моделью R1. `mixed_categories`-
guard сохранён для заказов без `service_code` (прежнее поведение).

## Честные отклонения
1. **Разъезд требует `service_code` у заказа-корзины.** Существующий клиент его
   не шлёт → заказы остаются плоскими (байт-в-байт). Гостевой редизайн (R5) начнёт
   слать код сервиса; демо/тесты шлют его уже сейчас. Инфер сервиса из позиций
   невозможен (заимствованная позиция знает лишь источник, не агрегатора).
2. **Аналитика `accepted` у фанного заказа приблизительна.** parent не эмитит
   `ORDER_ACCEPTED` (принимают children); выручка/создание/завершение/отмена —
   точны на parent. Атрибуция выручки — на сервис-агрегатор (позиции — на реальных
   исполнителей). Осознанно; полноценные per-executor ops-метрики — R3.
3. **Локация заимствованного блока** в меню не фильтруется по `ServiceLocation`
   источника (корзина — включающего сервиса, его доставка). Уточнение — R4.
4. **Инфра-фикс (не R2-логика):** `core/0002_rls` читал живой `TENANT_TABLES`, но
   шёл раньше миграций части таблиц — на РЕАЛЬНО чистой пересборке БД падал. Добавлен
   guard `to_regclass` в `enable_sql`/`disable_sql`; политику каждой таблице ставит
   миграция после её создания, сторож покрытия проверяет итог. (R1 не ловил из-за
   переиспользования старой тест-БД.)

## СТОП-точки
Жёстких СТОП не было. Модель заказа разъехалась чисто через суб-заказы
(подтверждено пользователем как выбор механизма). Quote с overlay сходится со
снимком (тест). Циклы отклоняются на записи. Единый источник правды — тестом
подтверждён (правка источника → у заёмщика без копии).

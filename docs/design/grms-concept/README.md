# Концепт гостевого экрана управления номером (GRMS)

Исходники визуальной концепции. Это **справочные материалы**, а не боевые ассеты:
рендер попадает в приложение не отсюда, а через media-pipeline (`MediaAsset`, MinIO),
геометрия — через `payload.plan` опубликованного конфига типа номера.

## Решения, которые нельзя переигрывать молча

**Два кадра, и ночной СЧИТАЕТСЯ из светлого.** Плита — два попиксельно совмещённых кадра:
нижний ночной виден всегда, верхний светлый показывается только в зонах, где свет
подтверждённо включён, с растушёвкой по краю зоны. Затемняющая маска поверх светлого кадра
это не заменяет: тонировка выглядит как дневная комната под серой плёнкой, а не как тёмная
комната.

Совмещение — условие работы, а не пожелание: разойдись кадры на несколько пикселей, и на
границе включённой зоны появится двойная мебель. Поэтому ночной кадр не рисуется, а считается
из светлого (`bake_dark_plate.py`): это те же пиксели, к которым применена цветовая функция —
кадр делится на размытую освещённость, тёплые пятна ламп гасятся дополнительно, остаток
уводится в холод. Геометрию скрипт не трогает вовсе.

Нарисованный отдельно `render-type1-dark.png` этому условию не отвечает: габариты комнаты
расходятся примерно на 21% (светлый x 310–1260 px, тёмный x 217–1365 px при одинаковом размере
кадра 1586×992), при подгонке по стенам мебель двоится. Он оставлен как референс настроения.

**Ночного кадра может не быть.** Тогда плита падает назад на прежнее поведение — один кадр и
затемняющая маска по выключенной зоне. Хуже на вид, но честно: новый тип номера подключается
без посчитанного кадра, а не с битой картинкой.

**Геометрия — в процентах и в конфиге типа.** Не в пикселях и не в коде компонента:
новый тип номера с другим рендером должен подключаться без правки фронта.

**Плита плана — фотография, а не поверхность интерфейса.** Она остаётся тёмной в обеих темах;
меняется только обрамление. Прецеденты в проекте те же: обложка отеля, плитка витрины —
читаемость обеспечивается скримом, а не режимом.

**Честность под железо.** В макете нет диммирования, цветовой температуры, процентов открытия
шторы и датчиков влажности/AQI/CO₂ — потому что их нет в переменных ПНР. Не дорисовывать.

## Если рендер типа номера меняется

Пересчитать `plan-geometry.json` под новый кадр. В макете для этого есть режим разметки:
клавиша `G` показывает все зоны и окна, стрелки двигают, Shift меняет размер,
Alt даёт шаг 0.2%, кнопка копирует готовые координаты.
